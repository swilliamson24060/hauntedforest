# Hollowmere — A Haunted Forest

A self-contained, atmospheric browser exploration with 24 haunted locations. Built with Canvas 2D and Web Audio: no build step, packages, API keys, or game engine required. Non-gory supernatural encounters, procedural moonlit woodland, fog, moving foliage, water, apparitions, wind, breath-like whispers and tonal haunting effects.

## Play locally
Open `index.html` in a modern browser, or serve this directory with any static web server. Enable **Sound on** for audio (browsers require a click before playback). Headphones recommended. Google Fonts is optional; system serif/sans fonts work offline.

- Mouse / touch: drag the background to look around.
- Follow the path buttons to travel; the Map also allows direct travel to all 24 places.
- Listen to the darkness to reveal a haunting and record it.
- Keyboard: E encounter, M map, J journal, Escape close dialog.
- Settings: reduced motion, lighter graphics, sound volume.
- Discoveries persist locally on this browser, when browser storage is available.

This is a scene-based exploration, not a first-person 3D walking simulator. Graphics are procedural illustrations. Whispers are synthetic breath/noise rather than recorded spoken dialogue. All locations are available immediately; discovering all hauntings completes the journal.

## GitHub Pages
Create an empty GitHub repository named `hauntedforest`, add it as the remote, and push `main`. In repository Settings → Pages select **Deploy from a branch**, **main**, **/(root)**. All asset paths are relative, so project Pages works without edits. `.nojekyll` bypasses Jekyll processing. No server required.

## itch.io
Upload the supplied `hauntedforest-itch.zip` as an **HTML** game and select **This file will be played in the browser**. Its `index.html` is at the ZIP root. Enable mobile support and fullscreen; a 1280 × 800 embed is a good desktop starting size. The layout resizes automatically. Audio begins only after Sound on is selected.

## Source layout
- `index.html`: accessible HTML controls and panels
- `style.css`: responsive layout and visual styling
- `game.js`: location data, exploration, journal, procedural renderer and audio

Artwork and audio are generated by the included code. No external image/audio assets are used. Works with current Canvas 2D/Web Audio-capable desktop and mobile browsers. Real-device performance and audio vary; lighter graphics reduces rendering load. No analytics or tracking.
